Meet Guilty Spark 343

An independent conversation workspace combining a local Ollama-compatible runtime with chat, character, persona, and history features inspired by GobboNet.

◈
A local workspace

Chats, characters, persona, and preferences are saved in this browser’s local storage. Clearing browser data removes them. Export a backup to keep a portable copy.

⬡
One shared runtime

Messages are sent to this server’s native chat API. Selecting a model changes the next request. Stop cancels the active request; replies depend on the selected model and available hardware.

↥
Imports with visible limits

Supported JSON backups and character data can be imported. Advanced original-app features are not reproduced in full. Import warnings identify omitted or unsupported data; this workspace does not claim full GobboNet equivalence.

Runtime details will appear when the server is available.
