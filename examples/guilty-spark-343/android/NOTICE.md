# Third-party build tooling

The Gradle wrapper scripts and `gradle/wrapper/gradle-wrapper.jar` are generated by Gradle 8.14.3 and distributed under Apache License 2.0. The scripts retain their original copyright and license headers. The wrapper JAR includes the full license at `META-INF/LICENSE`.

Android Gradle Plugin, Android SDK and JDK dependencies are build tools fetched or discovered locally; their binaries are not added to the source tree or included as application libraries. The APK uses Android framework APIs and the device's Android System WebView. Guilty Spark server web content is loaded from the server chosen by the user, not bundled into this APK.
